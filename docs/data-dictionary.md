# Data Dictionary — Sample Superstore

Dataset of retail orders (one row = one order line). Orders span from **January 2023 to April 2026**.
Source: Sample Superstore (public demo dataset by Tableau).

## Table: Orders

| Column | Type | Description |
|---|---|---|
| Row ID | Integer | Unique identifier of the order line |
| Order ID | Text | Unique identifier of the order (an order can have several lines) |
| Order Date | Date | Date the order was placed |
| Ship Date | Date | Date the order was shipped |
| Ship Mode | Text | Shipping method (Standard Class, First Class, Second Class, Same Day) |
| Customer ID | Text | Unique identifier of the customer |
| Customer Name | Text | Full name of the customer |
| Segment | Text | Customer segment (Consumer, Corporate, Home Office) |
| Country/Region | Text | Country of the customer |
| City / State / Postal Code | Text / Text / Text | Geographic details of the customer |
| Region | Text | Sales region (Central, East, South, West) |
| Product ID | Text | Unique identifier of the product |
| Category | Text | Product category (Furniture, Office Supplies, Technology) |
| Sub-Category | Text | Product sub-category (Chairs, Tables, Phones, Paper...) |
| Product Name | Text | Name of the product |
| Sales | Decimal | Revenue generated by the order line (currency) |
| Quantity | Integer | Number of units sold |
| Profit | Decimal | Profit generated by the order line (can be negative = loss-making sale) |
| Discount | Decimal | Discount applied to the order line (0 to 1) |

## DAX Measures

| Measure | Definition |
|---|---|
| Total Sales | Sum of all Sales |
| Total Profit | Sum of all Profit (includes loss-making lines) |
| Profit Margin | Total Profit / Total Sales (0 if no sales) |
| Total Orders | Count of distinct Order IDs |
| Average Order Value | Total Sales / Total Orders |
| Total Customers | Count of distinct Customer IDs |
